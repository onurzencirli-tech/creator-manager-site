Creator Manager

Privacy Policy

Last updated: 1 October 2026

Data we access

When the owner connects an account, Creator Manager receives only what the owner approves on the platform's consent screen. For TikTok this is basic profile information (open ID, display name, avatar) and permission to upload and publish videos to that account.

Where data is stored

Access tokens and account details are stored only on the owner's own computer. They are not sent to any server operated by Creator Manager; there is none. This website is static and stores nothing.

How data is used

Data is used only to show the connected account in the application and to publish content the owner chooses to publish. It is not sold, shared with third parties, or used for advertising.

Deleting data

Disconnecting an account in Creator Manager deletes its stored tokens. Access can also be revoked at any time from the platform's own settings (on TikTok: Settings and privacy → Security → Manage app permissions).
